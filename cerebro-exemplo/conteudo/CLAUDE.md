# conteudo

Tudo o que o cérebro entrega. O painel monta a galeria a partir daqui.

| Pasta | Uma subpasta por | Exemplo que já vem pronto |
|---|---|---|
| `carrosseis/` | carrossel (`AAAA-MM-DD-<tema>/`) | `2026-10-20-habitos-que-rendem/` |
| `thumbnails/` | vídeo (`<slug-do-video>/`) | `rotina-da-manha/` |
| `reels/` | vídeo editado (`<numero>-<slug>/`) | `01-tres-erros-de-iniciante/` |
| `whatsapp/` | envio (`AAAA-MM-DD-<assunto>.md`) | `2026-10-25-cardapio-da-semana.md` |

Toda entrega tem `pedido.md`. Se o cérebro foi instalado sem exemplos, as pastas acima começam vazias: atualize esta tabela quando a primeira entrega chegar.
