# Lições

> Cada correção vira uma regra curta, para o mesmo erro não voltar.

**Texto em imagem é sempre HTML e CSS.**
O gerador de imagem troca letras e inventa palavras; ele só faz a ilustração.

**Capa nunca corta a pessoa no rosto.**
Queixo, testa ou olhos cortados deixam a capa com cara de erro.

**Na gravação repetida, vale o último take.**
Os primeiros costumam ser ensaio; o último é o que a pessoa quis dizer.

**Cada coisa vai direto para o destino.**
Pasta de "organizar depois" vira gaveta esquecida.

**Sem travessão.**
O dono não usa; vírgula, dois-pontos ou ponto resolvem.
